# 3단계: 목표 1,024트랙에서 설계별 지표 — XL INT8, 256레인, 막전위 DDR3, rev 4

시뮬레이션 값. 시나리오 U·K·S·I·SK·R × 시드 20개, 실행마다 측정 구간 64주기(2.048 s). 위반율·평균·p99는 모든 요청을 합친 값. 평균 처리 시간 = 생성 → 결과가 호스트에 도착(호스트 1 ms 묶음 입출력 포함), 괄호 = FPGA 안(도착 → 연산 완료). 오프칩 접근 = 요청당 DDR3 DMA 횟수(가중치: 한 번에는 묶음당 1회, 한 줄씩은 적재하는 뉴런 그룹마다 1회. 막전위: 읽기·쓰기 2회), 괄호 = 가중치 DMA만. 1 DMA는 AXI 256 bit(32 B) 버스트 여러 개로 나뉘며, 32 B 단위 접근 수 = KB × 32다.

사이클(100 MHz): 요청당 연산은 모든 설계가 2,385.9사이클(2,169 word × 1.1)로 같다. DMA = 요청당 DDR3 데이터 이동 사이클(가중치 + 막전위). 연산 배열 사이클 = 요청당 (연산 + 정지), 정지 = FPGA에 요청이 있는데 연산 배열이 가중치를 기다린 사이클. 요청이 계속 도착하는 U·K·I·R에서는 FPGA 안에 대기 요청이 늘 있어 쉬는 시간이 모두 정지가 되므로, 이 값은 설계와 무관하게 측정 구간 ÷ 요청 수(U 3,125)가 된다. 여유는 유휴 시간이 아니라 더 작은 묶음(더 많은 전송)으로 쓰인다. 그래서 설계 차이는 동시 도착 S의 몰림 처리 사이클로 본다. 정지 비율 = 측정 구간 중 정지 사이클 비율(전 시나리오). 굵은 글씨 = 위반 0.
