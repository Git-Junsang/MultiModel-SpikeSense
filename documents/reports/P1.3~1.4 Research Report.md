## 1. 요약

선행 SpikeSense-Edge의 `snn_model.py`(`40→128→32→2`, 가중치 9,280개)를 확장해 이 프로젝트의 확정 구조 **`40→384→256→64→2`**(가중치 130,176개, 뉴런 706개)를 구현했다.

| 항목               | 결과                                                                                                         |
| ------------------ | ------------------------------------------------------------------------------------------------------------ |
| 구현 위치          | `software/model_develop/snn_model.py`                                                                      |
| 가중치             | **130,176개** = 127.125 KiB (INT8), PROPOSAL.md §3.1 계산값과 일치                                    |
| 뉴런               | **706개** (384 + 256 + 64 + 2)                                                                         |
| PLIF 학습 파라미터 | 1,412개 (뉴런당 beta·threshold 2개)                                                                         |
| 선행 모델과의 동치 | `40→128→32→2`로 설정하면 순전파 출력 3종과 기울기가 **비트 단위로 동일**(최대 절대오차 0.000e+00) |
| 뉴런 갱신 규칙     | 선행`hardware/src/plift_core.v`와 동일(누설 → 적분 → 발화 → soft reset)                                 |

이 단계의 핵심 판단은 **"구조만 키우고 뉴런 규칙은 한 글자도 바꾸지 않는다"**였다. 뉴런 규칙은 재사용 대상 RTL 모듈(`plift_core.v`)과 P1.7 INT8 골든 참조가 공유하는 계약이기 때문이다. 층 수와 폭만 일반화하고, 선행 코드에 상수로 박혀 있던 부분(층 3개 고정, beta 그룹 크기 고정)을 임의 구조로 확장했다.

구현 후 학습된 가중치로 뉴런 동특성을 측정해(§6) **막전위 16 bit와 현재 활성함수를 유지해도 된다**는 것을 확인했다. 이 측정은 P1.4 학습이 끝난 뒤 수행했으므로 시점상 P1.3 이후지만, 결론이 P1.3의 설계 선택(뉴런 규칙 동결)을 뒷받침하므로 여기에 함께 싣는다.

## 2. 이 단계의 목적과 제약

### 2.1 목적

PROPOSAL.md가 확정한 모델 크기(127.125 KiB)를 실제로 만들어, 이후 단계가 쓸 가중치·뉴런 수를 코드로 확정하는 것이다. 이 숫자는 다음 계산 전체의 입력이다.

- BRAM 예산: 막전위 512 × 706 × 2 B = 706 KiB, 모델 1벌 127.125 KiB
- 전송 시간: 모델 전체 65.088 µs, 재사용 없는 전송률 2.083 GB/s
- 트랙 경계: 대역폭 491 / 연산 786 / 막전위 934

### 2.2 제약

| 제약                                    | 근거                                                        |
| --------------------------------------- | ----------------------------------------------------------- |
| 뉴런 갱신 규칙을 선행과 동일하게 유지   | `plift_core.v`를 재사용 기준으로 삼는다 (AGENTS.md)       |
| 입력 40차원, 출력 2클래스               | mel 40차원·32 ms 주기, P1.1에서 2클래스 확정               |
| 판정 = 출력층 막전위 시간 평균의 argmax | 선행`anomaly_judge` 계열과 동일                           |
| 가중치는 bias 없음                      | INT8 HEX 내보내기(P1.6)와 MAC 구조가 bias를 가정하지 않는다 |
| 선행 저장소를 수정하지 않음             | 동결된`snn_top.v`·`dual_snn_top.v` 보호 (AGENTS.md)    |

### 2.3 선행 모델의 구조적 한계

선행 `snn_model.py`는 3층 고정이다. 다음이 코드에 상수로 박혀 있었다.

- `self.n_hidden1 = 128`, `self.n_hidden2 = 32`, `self.n_output = 2`
- `fc1`, `fc2`, `fc3` / `hidden1_lif`, `hidden2_lif`, `output_lif` 개별 속성
- `forward`에서 세 층을 순서대로 펼쳐 쓴 코드
- beta 초기값 그룹이 층 크기에 맞춰 손으로 쓴 리스트 (`[0.70]*32 + [0.80]*32 + [0.90]*32 + [0.95]*32`)

층을 하나 더 넣고 폭을 바꾸려면 이 네 곳을 모두 고쳐야 했다. 그래서 층 수·폭을 인자로 받는 형태로 일반화했다.

## 3. 구현 — 무엇을 바꿨는가

선행 파일과 비교해 바꾼 곳은 다섯 군데다. **뉴런 수식은 바꾸지 않았다.**

### 3.1 구조를 인자로 받도록 일반화

| 선행                                                     | 신규                                                                   |
| -------------------------------------------------------- | ---------------------------------------------------------------------- |
| `n_hidden1=128`, `n_hidden2=32`, `n_output=2` 상수 | `LAYER_SIZES = (40, 384, 256, 64, 2)`, `__init__(layer_sizes=...)` |
| `fc1`, `fc2`, `fc3` 개별 속성                      | `self.fcs = nn.ModuleList()`                                         |
| `hidden1_lif`, `hidden2_lif`, `output_lif`         | `self.lifs = nn.ModuleList()`                                        |
| `forward`에서 3층을 펼쳐 씀                            | `for i, (fc, lif) in enumerate(zip(self.fcs, self.lifs))` 반복       |

층 수는 `layer_sizes` 길이로 결정된다. 가중치 초기화는 선행과 같이 모든 층에 `xavier_normal_(gain=5.0)`을 쓴다.

### 3.2 beta 그룹 초기화 일반화

선행은 은닉층 1을 32개씩 4그룹(0.70 / 0.80 / 0.90 / 0.95), 은닉층 2를 8개씩 4그룹(0.75 / 0.85 / 0.90 / 0.95)으로 나눠 다중 시간상수를 준다. 이 의도를 임의 뉴런 수로 옮기기 위해 `grouped_beta(n_neurons, betas)`를 추가했다. 뉴런을 그룹 수만큼 균등 분할하고 나머지는 마지막 그룹에 붙인다.

```
INIT_BETAS = (
    (0.70, 0.80, 0.90, 0.95),   # L1 384 = 96 × 4
    (0.75, 0.85, 0.90, 0.95),   # L2 256 = 64 × 4
    (0.75, 0.85, 0.90, 0.95),   # L3  64 = 16 × 4  (새 층, L2 값을 따름)
    0.85,                        # L4   2  (선행 출력층과 동일, 스칼라)
)
```

새로 생긴 은닉층 3은 선행에 대응 층이 없다. 은닉층 2의 값을 그대로 쓰기로 했다. 근거는 선행이 깊은 층일수록 긴 시간상수 쪽으로 옮겨 놓았고(0.70→0.75 시작), 은닉층 3이 은닉층 2와 같은 역할 구간에 있다고 본 것이다. **이 선택은 실험으로 비교하지 않았다.**

`n_neurons // len(betas)`가 나누어떨어지므로 384 = 96 × 4, 256 = 64 × 4, 64 = 16 × 4로 정확히 균등 분할된다.

### 3.3 PLIFLayer 정리

선행은 `init_beta`가 스칼라인지 리스트인지에 따라 `w_beta`를 다르게 만드는 분기가 있었다. `np.broadcast_to`로 합쳐 한 줄로 만들었다. 결과 텐서는 선행과 동일하다(§4에서 확인).

`forward`의 수식과 `torch.clamp(self.w_thr, min=0.1)` 임계값 하한은 선행 그대로다. `.to(device)` 호출만 제거했다 — 파라미터가 이미 모듈과 같은 장치에 있어 불필요하다.

### 3.4 출력 형태 유지

`forward`의 반환은 선행과 같은 3종이다.

- 출력 스파이크 `[B, T, 2]`
- 출력 막전위 `[B, T, 2]` — 판정에 쓰는 값
- **마지막 은닉층** 스파이크 `[B, T, 64]` — 선행은 은닉층 2(32개)를 돌려줬다. 층이 늘었으므로 `spikes[-2]`로 "마지막 은닉층"을 돌려주도록 바꿨다. 학습·분석 코드에서 희소성 확인 용도로만 쓴다.

### 3.5 검산용 보조 함수 추가

`weight_count()`, `neuron_count()`, 모듈 상수 `N_WEIGHTS = 130,176`, `N_NEURONS = 706`을 추가했다. `python3 snn_model.py`로 직접 실행하면 층별 가중치 수를 출력하고 두 상수와 대조한 뒤 순전파·역전파를 한 번 돌린다. 설계 문서의 숫자가 코드와 어긋나는 것을 막기 위한 장치다.

### 3.6 층별 가중치

| 층             | 형태       | 가중치 수         | INT8 바이트                       |
| -------------- | ---------- | ----------------- | --------------------------------- |
| L1             | 40 → 384  | 15,360            | 15,360 B                          |
| L2             | 384 → 256 | 98,304            | 98,304 B                          |
| L3             | 256 → 64  | 16,384            | 16,384 B                          |
| L4             | 64 → 2    | 128               | 128 B                             |
| **합계** |            | **130,176** | **130,176 B = 127.125 KiB** |

L2 한 층이 전체의 **75.5%**를 차지한다. 슬라이스 단위 전송·부분 상주를 설계할 때 L2가 실질적인 대상이다.

## 4. 검증

`software/model_develop/verify_reference.py`로 수행했다. 신규 모델을 `40→128→32→2`, beta 그룹을 선행과 같게 설정한 뒤 선행 모델과 비교했다.

| 확인 항목                             | 결과                                                   |
| ------------------------------------- | ------------------------------------------------------ |
| beta 초기값 (복사 전, 초기화만으로)   | L1·L2·L3 모두 일치                                   |
| 출력 스파이크`[8, 31, 2]`           | 최대 절대오차**0.000e+00**, `torch.equal` True |
| 출력 막전위`[8, 31, 2]`             | 최대 절대오차**0.000e+00**, `torch.equal` True |
| 은닉 스파이크                         | 최대 절대오차**0.000e+00**, `torch.equal` True |
| 역전파 기울기 (fc1 가중치, L1 임계값) | 최대 절대오차**0.000e+00**                       |
| 확정 구조 파라미터 수                 | 가중치 130,176 / 뉴런 706 / PLIF 1,412                 |

가중치와 PLIF 파라미터를 선행에서 복사한 뒤 같은 입력을 넣어 비교한 것이다. 기울기까지 같으므로 surrogate gradient 경로도 동일하다. **일반화 과정에서 수식이 바뀌지 않았음을 확인했다.**

추가로 `python3 snn_model.py` 자체 검증에서 `N_WEIGHTS`·`N_NEURONS` assert 통과, 전 파라미터에 기울기가 흐르는 것을 확인했다.

## 5. 하드웨어 규칙과의 정합

선행 `hardware/src/plift_core.v`의 연산 순서와 신규 모델의 `PLIFLayer.forward`를 대조했다.

| 단계 | RTL (`plift_core.v`)                            | PyTorch (`PLIFLayer.forward`)                   |
| ---- | ------------------------------------------------- | ------------------------------------------------- |
| 누설 | `decayed = (beta × mem_in) >>> 8` (Q0.8)       | `beta * membrane`, `beta = sigmoid(w_beta)`   |
| 적분 | `mem_new = decayed + current`                   | `+ input_current`                               |
| 발화 | `spike = (mem_new >= vth_ext)`                  | `spike_fn(membrane, thr)` = `membrane >= thr` |
| 리셋 | `mem_out = spike ? mem_new - vth_ext : mem_new` | `membrane - spikes * thr`                       |

순서와 비교 방향(`>=`)이 같다. 학습 파라미터는 하드웨어에서 beta가 Q0.8 uint8, 임계값이 INT8 양수로 들어가고, 막전위는 **16-bit signed**다. 이 폭에 실제로 들어가는지는 §6에서 확인했다.

surrogate gradient는 학습에만 쓰이므로 RTL에 대응물이 없다. 추론 시 발화 조건은 순수 비교 연산이다.

## 6. 구현 후 점검 — 뉴런 규칙을 바꿔야 하는가

P1.4에서 40대를 학습한 뒤, 학습된 가중치로 test 세그먼트를 흘려 뉴런 동특성을 측정했다. 구조를 4.4배 키웠으므로 선행에서 검증된 규칙이 그대로 통하는지 확인이 필요했다.

### 6.1 발화율

층별 0.21 / 0.46 / 0.47이다. 죽은 뉴런도 포화도 없다. 학습된 임계값이 하한 0.1 클램프에 걸린 뉴런은 L1 84/384, L2 42/256, L3 11/64개다.

### 6.2 막전위 범위 — float에서는 넓지만 하드웨어 단위에서는 문제 없음

float 기준으로는 L1 −16.9~+26.7, L2 −58.3~+52.7, L3 **−95.4~+152.4**로 임계값(약 0.7)의 200배를 넘는다. soft reset은 발화할 때만 임계값을 빼므로 음수 쪽에 바닥이 없고, 억제된 뉴런의 막전위가 계속 쌓인다(L3 뉴런의 48%가 매 시점 −5 아래).

그러나 선행 `export_weights.py`의 양자화 규칙(`scale_W = max|W| / 127`, `막전위_int ≈ V_float / scale_W`)으로 40대를 모두 환산하면 다르다. **정수 단위에서는 임계값이 1이 아니라 110 근처**이므로 비율이 그대로 옮겨지지 않는다.

| 층 | 막전위 최대(정수, 40대 최악) | INT16(32,767) 대비 | `vth_q` 최대 |
| -- | ---------------------------- | ------------------ | -------------- |
| L1 | 3,446                        | 10.5%              | 110            |
| L2 | 8,544                        | 26.1%              | 116            |
| L3 | **16,707**             | **51.0%**    | 118            |
| L4 | 4,276                        | 13.0%              | 57             |

INT16을 넘는 장비는 **0/40**이고 `vth_q`도 모두 127 이하라 선행과 같은 INT8 임계값을 쓸 수 있다. 여유가 가장 적은 층은 L3로 약 2.0배다.

### 6.3 막전위 폭을 늘리면 설계가 무너진다

| 막전위 폭            | 512트랙 점유      | 남는 BRAM (1,642.5 KiB 중) | 결과                                       |
| -------------------- | ----------------- | -------------------------- | ------------------------------------------ |
| **2 B (현행)** | 706 KiB (43.3%)   | 936.5 KiB                  | 캐시 여러 벌 비교 가능                     |
| 3 B                  | 1,059 KiB (64.5%) | 583.5 KiB                  | 부분 상주 비교 폭이 크게 줄어듦            |
| 4 B                  | 1,412 KiB (86.0%) | 230.5 KiB                  | 캐시 1벌 + 프리페치 1벌(254.25 KiB)도 불가 |

이 연구의 가설은 "부분 상주가 전체 캐시보다 낫다"이고 그 비교는 남는 BRAM 안에서 이뤄진다. 막전위 폭을 늘리면 비교 대상 자체가 사라진다. §6.2의 측정과 합쳐 **16 bit 유지**로 결론냈다.

### 6.4 출력층 soft reset을 없애는 안 — 채택하지 않음

판정은 출력층 막전위의 시간 평균인데, 출력 뉴런도 발화할 때마다 soft reset으로 그 막전위를 깎는다. 출력 발화율이 높은 장비에서 판독이 압축되는 것을 확인했다(제외 장비 `fan_id00`: 출력 발화율 0.537, 리셋을 없애면 로짓 폭 std 1.97 → 3.59, 세그먼트 10.7%에서 판정이 바뀜).

40대 전부를 리셋 없이 재평가한 결과는 다음과 같다.

|               | 리셋 있음(현행)  | 리셋 없음                   |
| ------------- | ---------------- | --------------------------- |
| 평균 파일 AUC | **0.9563** | 0.9543                      |
| 평균 균형 F1  | **0.8231** | 0.8184                      |
| 장비별        | —               | 오른 장비 14 / 내린 장비 24 |

이득이 없다. 리셋을 켠 채 학습한 모델을 끈 채 평가한 것이라 확정하려면 재학습이 필요하지만, 현재 근거로 규칙을 바꿀 이유가 없고 바꾸면 `plift_core.v` 재사용과 P1.7 골든 참조가 복잡해진다. **선행과 동일한 규칙을 유지한다.**

막전위 하한 클램프(`V ≥ -thr`)도 검토했으나, 목적이 범위 축소였고 그 범위가 문제가 아님이 확인되어 근거가 사라졌다.

## 7. 확인한 것과 확인하지 않은 것

**확인한 것**

- 신규 모델을 `40→128→32→2`로 설정하면 선행 모델과 순전파 출력 3종·역전파 기울기가 비트 단위로 같다
- 확정 구조의 가중치 130,176개·뉴런 706개·PLIF 파라미터 1,412개
- 뉴런 갱신 순서와 발화 조건이 `plift_core.v`와 일치한다
- 학습된 40대 모델의 막전위가 INT16에 들어가고(최악 51.0%), `vth_q`가 INT8에 들어간다(최대 118)
- 출력층 리셋 제거는 40대 사후 재평가에서 이득이 없다

**확인하지 않은 것**

| 항목                                                                                       | 어디서 하는가                                       |
| ------------------------------------------------------------------------------------------ | --------------------------------------------------- |
| 은닉층 3의 beta 초기값(은닉층 2 값 차용)이 최선인지                                        | 미측정. 대안과 비교하지 않았다                      |
| INT8 양자화 후 실제 정확도 저하폭과 막전위 포화 발생률                                     | P1.5                                                |
| `40→384→256→64→2`(127 KiB)가 선행 `40→128→32→2`(9 KiB)보다 정확도 이득이 있는지 | 미측정. P1.1~1.2 리포트 §7의 남은 판단과 같은 항목 |
| 출력층 리셋 제거를 적용해**재학습**했을 때의 성능                                    | 미수행                                              |
| RTL과의 비트 일치                                                                          | P1.7(NumPy 골든), P3.1(xsim)                        |
| 786뉴런 기준 연산 자원이 32레인·100 MHz에서 맞는지                                        | P2.x                                                |

## 8. 남은 판단 사항

1. **모델 크기의 정당화**: P1.1~1.2 리포트에서 이어지는 항목이다. 127 KiB 모델이 9 KiB 모델보다 정확도가 나은지 측정해야 "대역폭 문제를 만들기 위한 크기"라는 서술을 피할 수 있다. 같은 DCASE 40대에 선행 구조를 학습시키면 바로 비교된다.
2. **L3 여유 2.0배**: 40대에서는 포화가 없지만 여유가 가장 적은 층이다. P1.5에서 층별 포화 발생률과 float 대비 판정 일치율을 함께 기록한다.
3. **은닉층 3의 시간상수**: 근거가 "은닉층 2를 따랐다"뿐이다. 정확도에 여유가 생기면 비교 실험 대상이다.
4. **출력층 리셋**: 현재 근거로는 유지가 맞지만, 재학습 비교를 하지 않았다는 점을 기록해 둔다. P1.5 이후 여유가 있으면 확인한다.
