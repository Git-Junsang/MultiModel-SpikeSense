## 2. Model export

`export_models.py`는 checkpoint를 읽고 `snn_int8.quantize`를 호출한다. Quantization 규칙을 다시 구현하지 않는다.

| layer | weight |
|---|---:|
| L1 | 15,360 B |
| L2 | 98,304 B |
| L3 | 16,384 B |
| L4 | 128 B |

각 layer 시작은 128 B 경계다. β와 threshold도 model slot에 넣는다. 자세한 주소는 MODEL_MEMORY_LAYOUT.md를 따른다.

## 3. Golden vector

`snn_int8.forward`를 정수 동작의 기준으로 쓴다. Golden generator는 checkpoint가 아니라 `model.slot.bin`을 읽는다. 이 방식은 export 순서와 부호 오류도 잡을 수 있다.

NPZ 배열은 `[timestep, neuron]` 순서다.

- `cur_lN`: layer current
- `mem_pre_lN`: saturation 뒤, fire 전 membrane potential
- `spk_lN`: spike
- `mem_lN`: soft reset 뒤 저장 membrane potential

대표 vector는 `$readmemh`용 flat HEX도 제공한다.

## 4. Saturation test

실데이터 80개에서는 saturation이 없었다. 그래서 weight와 input을 크게 만든 artificial model 2개를 만들었다.

| Vector | L1 | L2 | L3 | L4 |
|---|---:|---:|---:|---:|
| 양수 | 9,600 | 7,936 | 1,920 | 54 |
| 음수 | 9,600 | 0 | 0 | 0 |

P4.1에서 이 vector로 saturation path를 확인한다.

## 5. 재현과 한계

```bash
python3 software/model/export_models.py
python3 software/model/export_golden.py
python3 software/model/verify_export.py
```

검증 결과:

```text
PASS: 모델 40개, 실데이터 80개, saturation 2개
```

이 결과는 software artifact의 내부 일치를 뜻한다. RTL bit 일치는 아직 확인하지 않았다. DMA slice와 parameter 상주 방식도 P3.9에서 정한다.
