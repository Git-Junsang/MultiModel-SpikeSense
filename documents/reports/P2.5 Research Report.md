# P2.5 보고서: INT8 quantization

작성일: 2026-09-25

## 1. 요약

40개 모델의 INT8 방식을 비교했다. 후보 간 평균 AUC 차이는 0.0006 이하였다. 가장 단순한 선행 방식을 쓰고, 16 bit saturation만 추가했다.

| 항목 | 결과 |
|---|---|
| weight | layer별 symmetric INT8 |
| β | Q0.8 `uint8` |
| threshold | `uint8` |
| membrane potential | signed 16 bit saturation |
| 평균 file AUC | 0.9563 → 0.9554 |
| Segment 판정 일치 | 96.5 % |
| test saturation | 0회 |
| 최대 membrane potential | L3 17,093, INT16의 52.2 % |

코드는 `snn_int8.py`, `quant_int8.py`, `quant_variants.py`다. 전체 장비 표는 `software/train_result/eval/quant_int8/results.csv`에 있다.

## 2. 평가 조건

- 모델: `40→384→256→64→2`, 40개
- 데이터: test segment 129,792개, file 12,671개
- FP32 기준: `snn_fp32.forward`
- 판정: 출력 membrane potential 31 timestep 평균의 argmax
- 재학습과 QAT는 하지 않음

## 3. 후보 비교

| 후보 | 평균 AUC | 특징 | 판단 |
|---|---:|---|---|
| FP32 | 0.9563 | 기준 | — |
| A_prior | 0.9554 | layer scale, wraparound | 미채택 |
| **A_sat** | **0.9554** | layer scale, saturation | **채택** |
| A_sat_rnd | 0.9553 | leak 반올림 | 이득 없음 |
| A_b12 | 0.9554 | β Q0.12 | 이득 없음 |
| A_b12_rnd | 0.9555 | Q0.12 + 반올림 | 비용 대비 이득 작음 |
| R_sat | 0.9557 | 뉴런별 scale | threshold 폭 증가 |
| R_b12_rnd | 0.9559 | 뉴런별 scale + Q0.12 | 복잡도 증가 |

결정 이유:

- 뉴런별 scale은 평균 AUC가 최대 +0.0005였다. threshold는 최대 135,467까지 커져 8 bit에 들어가지 않았다.
- β Q0.12는 accuracy 이득이 없었다.
- leak 반올림은 판정 일치가 0.2 %p 늘었지만 AUC는 같았다.
- wraparound는 overflow 때 부호가 바뀐다. saturation은 비용이 작고 안전하다.

## 4. 정수 규칙

### 4.1 변환

| 값 | 식 | 형식 |
|---|---|---|
| 입력 | `clip(round(mel × 127), 0, 127)` | 7 bit unsigned |
| weight | `round(W / (max|W|/127))` | INT8 |
| β | `round(beta × 256)` | Q0.8 uint8 |
| threshold | `round(thr / weight_scale)` | uint8 |

threshold 실제 범위는 layer별 최대 110, 116, 118, 57이다.

### 4.2 Timestep update

```text
L1 current = (Σ input_q × weight_q) >> 7
L2~L4 current = Σ spike × weight_q
mem = sat16(((beta_q × mem) >> 8) + current)
spike = mem >= threshold_q
mem = mem - spike × threshold_q
```

누설은 arithmetic shift로 내림한다. Reset은 soft reset이다.

## 5. RTL bit width

| Signal | 이론 최대 | 권장 폭 |
|---|---:|---:|
| L1 accumulator | 650,240 | signed 21 bit |
| L1 current | 5,080 | signed 14 bit |
| L2 current | 49,152 | signed 17 bit |
| L3 current | 32,768 | signed 16 bit |
| L4 current | 8,192 | signed 14 bit |
| leak + current | 81,920 미만 | signed 18 bit 뒤 16 bit saturation |

선행 `plift_core.v`의 16 bit current input은 넓혀야 한다. 누설, 비교, soft reset 규칙은 유지한다.

## 6. 정확도 결과

| 지표 | FP32 | INT8 | 변화 |
|---|---:|---:|---:|
| File AUC | 0.9563 | 0.9554 | −0.0009 |
| pAUC | 0.9209 | 0.9197 | −0.0012 |
| 균형 F1 | 0.8231 | 0.8186 | −0.0044 |
| 균형 accuracy | 0.8286 | 0.8262 | −0.0024 |

장비별 AUC 변화는 −0.0116~+0.0090이다. AUC 0.9 이상 장비는 35대로 같았다.

| layer | 최대 membrane potential | INT16 대비 | Saturation |
|---|---:|---:|---:|
| L1 | 3,729 | 11.4 % | 0 |
| L2 | 8,656 | 26.4 % | 0 |
| L3 | 17,093 | 52.2 % | 0 |
| L4 | 4,255 | 13.0 % | 0 |

Saturation 0은 test data 결과다. worst case 보장이 아니므로 saturation logic을 넣는다.

## 7. 기준 코드 확인

같은 `snn_int8.forward`에 선행 `40→128→32→2` weight를 넣었다. 정상·이상 golden 2개와 membrane potential·spike가 bit 단위로 같았다.

새 모델 RTL과의 bit 일치는 P4.1에서 확인한다.
