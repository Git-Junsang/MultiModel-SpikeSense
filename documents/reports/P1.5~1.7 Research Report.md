# P1.5~P1.7 보고서: 보드, DDR3, PCIe

작성일: 2026-09-23

## 1. 요약

| Task | 결과 |
|---|---|
| P1.5 | bitstream download와 200 MHz clock 동작 확인 |
| P1.6 | MIG calibration 성공, 360초 compare error 0 |
| P1.7 | PCIe Gen2 ×2, 64 KiB DMA 왕복 10/10 |

모든 값은 보드에서 확인했다. DDR3 대역폭과 PCIe 지연은 P3.1~P3.3에서 따로 측정했다.

## 2. 시험 환경

보드는 원격 FPGA Host에 있어 VIO로 내부 신호를 읽었다. Build는 개발 서버에서 하고 board test는 FPGA Host에서 했다.

주요 script:

| Script | 용도 |
|---|---|
| `program_fpga.tcl` | bitstream download, VIO read |
| `flash_qspi.tcl` | MCS 생성과 QSPI program |
| `pcie_reset_vio.tcl` | PCIe reset과 상태 확인 |
| `perst_latch.tcl` | PERST# pin 탐색 |
| `xdma_roundtrip.sh` | link와 DMA 왕복 test |

## 3. P1.5 보드 동작

`blink_top.v`는 LED 순환, counter, `sum(i², i=1..1000)` 계산을 한다.

| 확인 | 결과 |
|---|---|
| xsim | PASS |
| Verilator | warning 0 |
| implementation | WNS +0.170 ns |
| FPGA DONE | 1 |
| 계산 결과 | `0x13E5E51C`, 기대값과 일치 |
| clock | VIO counter로 약 200 MHz |
| LED logic | `0xE → 0x7`로 순환 |

물리 LED와 key는 직접 보지 못했다. VIO로 logic만 확인했다.

## 4. P1.6 DDR3

| 항목 | 값 |
|---|---|
| DDR3 | MT41J256M16 ×2, 1 GiB |
| Interface | 32 bit, 800 MT/s |
| MIG UI | 256 bit @ 100 MHz |
| Timing | WNS +0.963 ns, WHS +0.052 ns |
| Calibration | 완료 |
| Memory test | 360초, error 0 |

MIG가 만든 71개 pin은 project XDC와 모두 같았다. 이 test는 앞 16 MiB만 확인했다. 1 GiB 전체와 대역폭은 P3.1에서 확인했다.

## 5. P1.7 PCIe XDMA

### 5.1 구성

XDMA와 64 KiB AXI BRAM을 연결했다. FPGA는 Host SLOT5에 있고 slot 전원만 쓴다.

### 5.2 PERST# 문제

PERST#를 연결하지 않았을 때 link는 올라왔지만 BAR가 `0xffffffff`로 읽혔다. XDMA driver도 config BAR를 찾지 못했다.

manual에 PERST# pin이 없어 후보 pin 14개를 latch했다. Host boot 중 High→Low→High로 바뀐 pin은 L16뿐이었다. L16을 연결하자 XDMA가 정상 동작했다.

### 5.3 최종 결과

| 항목 | 결과 |
|---|---|
| Device | `0000:04:00.0`, `10ee:7022` |
| Link | 5 GT/s ×2 |
| GT lane | X0Y7, X0Y6 |
| Driver | Xilinx XDMA 2025.2.0 |
| Device node | H2C 1개, C2H 1개 |
| DMA | 64 KiB 무작위 data 10/10 일치 |
| Timing | WNS +0.486 ns, WHS +0.036 ns |

FPGA는 Host boot 전에 구성해야 BIOS가 안정적으로 장치를 찾는다. QSPI boot를 기본으로 쓴다.

## 6. 확인 범위

확인함:

- JTAG program과 FPGA logic
- MIG calibration과 제한 범위 memory test
- PCIe Gen2 ×2 link
- XDMA H2C·C2H data path
- PERST# L16

확인하지 않음:

- 물리 LED·key
- DDR3 실효 대역폭
- PCIe 지연·jitter
- 최종 accelerator resource와 timing

다음 측정은 [P3.1~P3.4 보고서](<P3.1~3.4 Research Report.md>)에 있다.
