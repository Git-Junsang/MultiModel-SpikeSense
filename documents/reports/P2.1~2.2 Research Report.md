# P2.1~P2.2 보고서: dataset, label, 모델 40개

작성일: 2026-09-23

## 1. 요약

| 결정 | 결과 |
|---|---|
| Dataset | DCASE 2020 Task 2 |
| 출력 | 정상/이상 2개 |
| 모델 수 | 기계 ID 41개 중 40개 |
| 학습 | 실제 이상을 쓰는 supervised learning |
| 당시 mapping 초안 | 균등, 편중, 재사용 없음 |

결함 종류 label이 있는 공개 dataset은 기계 수가 너무 적었다. DCASE는 기계 ID가 41개라 40개 personalized model 구성에 맞았다.

## 2. Dataset 선택

| Dataset | Label | 기계 수 | 판단 |
|---|---|---:|---|
| DCASE 2020 Task 2 | 정상/이상 | 41 ID | 채택 |
| MIMII | 정상/이상 | 16 | DCASE와 중복 |
| UOEMD | 8종 | 8 | 기계 수 부족 |
| KAIST | 5종 | 1 | 기계 수 부족 |
| MaFaulDa | 10종 | 1 | 기계 수 부족 |
| SSCC | 5종 | 1 | 기계 수 부족 |

결함 label dataset을 합쳐도 약 3.7시간이다. 40모델로 나누면 모델당 약 5.5분이고 정상은 약 19초다. DCASE는 ID 하나당 정상 72분~2.8시간이다.

따라서 기본 출력은 정상/이상 2개로 정했다. 결함 종류 분류는 optional experiment로 남겼다.

## 4. 2출력 변경

| 항목 | 이전 8출력 | 확정 2출력 |
|---|---:|---:|
| Weight/model | 130,560 B | 130,176 B |
| 뉴런 | 712 | 706 |
| 512트랙 막전위 | 712 KiB | 706 KiB |
| 재사용 없는 전송 | 2.089 GB/s | 2.083 GB/s |

출력 layer 차이는 전체 weight의 0.3 %다. 40개 모델이 BRAM에 모두 들어가지 않는 문제는 그대로다.

## 5. 모델 40개

처음에는 학습 data가 적은 `slider_id06`을 뺐다. 40대 학습 뒤 `fan_id00`의 AUC가 0.738로 가장 낮았고, `slider_id06`은 0.9982였다. 최종적으로 `fan_id00`을 제외했다.

최종 구성:

| 종류 | ID | 수 |
|---|---|---:|
| fan | 01~06 | 6 |
| pump | 00~06 | 7 |
| slider | 00~06 | 7 |
| valve | 00~06 | 7 |
| ToyCar | 01~07 | 7 |
| ToyConveyor | 01~06 | 6 |

이 선택은 평가 결과를 본 뒤 했다. 40대 평균 AUC 0.9563만 보고하면 selection bias가 있다. 41대 전체 평균 0.9510도 함께 기록한다.

## 6. 학습용 이상

`fan_id00`에서 세 방법을 비교했다.

| 방법 | 학습용 이상 | 실제 이상 test AUC |
|---|---|---:|
| other_id | 다른 ID의 정상 | 0.384~0.423 |
| mix | 다른 ID 정상음을 혼합 | 0.396~0.481 |
| real | 실제 이상 절반 | 0.689~0.755 |
| baseline | Mahalanobis, 학습 없음 | 0.564 |

가짜 이상은 validation에서는 0.99 수준이었지만 실제 이상을 구분하지 못했다. 그래서 실제 이상 파일 절반을 학습에 쓰는 supervised learning으로 바꿨다.

이 설정은 DCASE의 unsupervised challenge 조건과 다르다. Challenge leaderboard와 직접 비교하지 않는다. 이 연구에서는 scheduler 평가에 쓸 40개 실제 weight를 만드는 것이 목적이다.

## 7. 당시 track mapping 초안

| 조건 | 배정 | 목적 |
|---|---|---|
| U | 모델당 12~13트랙 | 균등 기준 |
| S | 인기 8모델 32트랙, 나머지 8트랙 | cache와 starvation |
| D | 모델당 1트랙만 active | 재사용 없음 |

이 표는 P2 단계 초안이다. P3.7에서 U, K, S, I, SK, R 시나리오로 바뀌었다.

## 8. 검증과 한계

확인함:

- archive 19개 MD5
- WAV 수와 기계 ID 41개
- 가짜 이상 실패와 supervised learning 이득
- 2출력으로 바뀐 모델·memory 계산

한계:

- 가짜 이상 비교는 `fan_id00` 한 대만 했다.
- 40대 선택에 test 결과가 들어갔다.
- 다른 dataset 수치는 공개 문서 값이며 직접 내려받지 않았다.
- 모델 크기의 필요성은 P3.6에서 따로 검증했다.
