# P2.3~P2.4 보고서: PLIF 모델 구현과 학습

작성일: 2026-09-23

## 1. 요약

선행 `40→128→32→2` 모델을 임의 layer 구조로 바꾸고, `40→384→256→64→2`를 구현했다.

| 항목 | 결과 |
|---|---|
| 구현 | `software/model/snn_torch.py` |
| weight | 130,176개, INT8 127.125 KiB |
| 뉴런 | 706개 |
| PLIF parameter | 1,412개 |
| 선행 model 호환 | output·gradient bit 일치 |
| 학습 | 모델 40개 완료 |
| 평균 file AUC | 0.9563 |

뉴런 식은 바꾸지 않았다. `plift_core.v`와 같은 `leak → integrate → fire → soft reset` 순서를 유지했다.

## 2. 구현

### 2.1 구조 일반화

| 선행 | 변경 |
|---|---|
| layer 3개를 개별 변수로 정의 | `ModuleList` 사용 |
| 크기 상수 고정 | `layer_sizes` argument |
| `forward`를 layer별로 반복 작성 | loop로 실행 |
| beta group을 수동 작성 | `grouped_beta()` 사용 |

기본 구조:

```text
40 → 384 → 256 → 64 → 2
```

초기 beta:

```text
L1: 0.70, 0.80, 0.90, 0.95
L2: 0.75, 0.85, 0.90, 0.95
L3: 0.75, 0.85, 0.90, 0.95
L4: 0.85
```

L3는 비교 실험 없이 L2 값을 썼다.

### 2.2 Model 크기

| layer | Shape | weight |
|---|---|---:|
| L1 | 40→384 | 15,360 |
| L2 | 384→256 | 98,304 |
| L3 | 256→64 | 16,384 |
| L4 | 64→2 | 128 |
| 합계 | | 130,176 |

L2가 75.5 %를 차지한다.

## 3. 선행 model 호환 검증

새 코드를 `40→128→32→2`로 설정하고 선행 model과 비교했다.

| 항목 | 최대 오차 |
|---|---:|
| output spike | 0 |
| output membrane potential | 0 |
| hidden spike | 0 |
| fc1 gradient | 0 |
| threshold gradient | 0 |

`verify_reference.py`에서 모두 bit 단위로 같았다. 일반화 과정에서 뉴런 수식과 surrogate gradient가 바뀌지 않았다.

## 4. RTL 규칙과 비교

| 단계 | PyTorch | 선행 RTL |
|---|---|---|
| leak | `beta × membrane` | `(beta × mem) >>> 8` |
| integrate | `+ current` | `+ current` |
| fire | `mem >= threshold` | `mem >= vth` |
| reset | `mem - spike × threshold` | spike면 threshold 감산 |

학습은 FP32, RTL은 fixed-point다. 순서와 비교 조건은 같다.

## 5. 학습 결과

40개 모델을 RTX 3090 Ti에서 학습했다.

| 항목 | 값 |
|---|---:|
| 총 시간 | 85.2분 |
| 모델당 평균 | 128초 |
| 평균 file AUC | 0.9563 |
| AUC ≥ 0.9 | 35대 |
| 최저 AUC | 0.8175, ToyCar_id05 |

41대 전체 평균은 0.9510이다. `fan_id00` 제외는 test 결과를 보고 한 선택이다.

세부 결과는 `software/train_result/L_normal_noaug/REPORT.md`에 있다.

## 6. 뉴런 상태 확인

### 6.1 spike rate

L1/L2/L3 평균 spike rate는 0.21/0.46/0.47이었다. 죽은 layer나 전체 saturation은 없었다.

### 6.2 INT16 membrane potential 예상 범위

40개 모델을 선행 quantization scale로 환산했다.

| layer | 최대 절댓값 | INT16 대비 |
|---|---:|---:|
| L1 | 3,446 | 10.5 % |
| L2 | 8,544 | 26.1 % |
| L3 | 16,707 | 51.0 % |
| L4 | 4,276 | 13.0 % |

INT16 범위를 넘은 모델은 없었다. membrane potential을 24·32 bit로 늘리면 BRAM이 크게 늘어 cache 비교가 어려워진다. 따라서 16 bit를 유지했다.

### 6.3 출력 layer reset

soft reset을 끄고 사후 평가했다.

| 조건 | 평균 AUC | 균형 F1 |
|---|---:|---:|
| reset 사용 | 0.9563 | 0.8231 |
| reset 제거 | 0.9543 | 0.8184 |

이득이 없어 기존 규칙을 유지했다. reset 없이 재학습한 실험은 하지 않았다.

## 7. 확인 범위

확인함:

- weight·뉴런·PLIF parameter 수
- 선행 model과 output·gradient 일치
- 40모델 학습과 accuracy
- INT16 state 범위

확인하지 않음:

- L3 beta 초기값 대안
- INT8 accuracy와 saturation
- RTL bit 일치
- 32 lane·100 MHz 구현 가능성

INT8 결과는 [P2.5 보고서](<P2.5 Research Report.md>)에 있다. 모델 크기의 정확도 근거는 MODEL_SIZE_PLAN.md에서 확인했다.
