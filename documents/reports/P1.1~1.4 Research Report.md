# P1.1~P1.4 보고서: 개발 환경과 보드 연결

작성일: 2026-09-23

## 1. 요약

| Task | 결과 |
|---|---|
| P1.1 | RTX 3090 Ti와 PyTorch CUDA 확인 |
| P1.2 | XC7A200T synthesis, xsim, Verilator 통과 |
| P1.3 | JTAG에서 `xc7a200t_0` 인식 |
| P1.4 | XDC 87개 port의 pin 배치 일치 |

이 단계는 개발 환경과 board constraint를 확인했다. 40모델·512트랙 성능은 확인하지 않았다.

## 2. 보드

| 항목 | 값 |
|---|---|
| 보드 | ALINX AX7A200B, core AC7A200 |
| FPGA | XC7A200T-2FBG484I |
| DDR3 | 1 GiB, 32 bit |
| PCIe | Gen2 ×2, connector는 x4 |
| system clock | 200 MHz differential |
| PCIe clock | 100 MHz from Host |

사양과 pin은 [board manual](../manual/AX7A200_User_Manual.pdf)을 기준으로 했다. PCIe Gen2 ×2는 P1.7에서 보드로 확인했다.

## 3. 개발 서버

| 항목 | 확인값 |
|---|---|
| OS | Ubuntu 24.04.4 LTS |
| CPU / RAM | i5-14600K, 12 vCPU / 16 GiB |
| GPU | RTX 3090 Ti, 24,564 MiB |
| Python / PyTorch | 3.12.3 / 2.13.0+cu130 |
| Vivado | 2026.1 |
| Verilator | 5.020 |

GPU matrix multiply, target part synthesis, xsim counter testbench, Verilator lint를 실행했다. 모두 통과했다.

Vivado IP build는 공백 없는 ASCII 경로에서 한다. 자세한 제약은 [ENVIRONMENT.md](../design/ENVIRONMENT.md)에 있다.

## 4. FPGA Host와 JTAG

| 항목 | 결과 |
|---|---|
| Host | `sdsl-llm`, Ubuntu 24.04.5 |
| JTAG adapter | FT232H, Digilent |
| FPGA | `xc7a200t_0` |
| IDCODE | `0x13636093` |

작업 순서:

1. 개발 서버에서 bitstream을 만든다.
2. 결과를 FPGA Host로 보낸다.
3. Host의 local JTAG로 program한다.
4. PCIe test는 Host에서 실행한다.

FPGA Host는 공용 장비다. reboot는 먼저 조율한다.

## 5. XDC와 build script

| 파일 | 내용 |
|---|---|
| `ax7a200b_base.xdc` | system clock, config |
| `ax7a200b_io.xdc` | LED, key, reset, UART |
| `ax7a200b_ddr3.xdc` | DDR3 pin |
| `ax7a200b_pcie.xdc` | PCIe clock과 lane |
| `create_project.tcl` | project, synthesis, implementation, bitstream |

dummy top을 네 XDC와 함께 배치했다. 결과:

- Error 0, Critical Warning 0
- 87개 port의 `PACKAGE_PIN` 불일치 0
- DDR3 I/O standard를 Artix-7 HR bank에 맞게 수정

이 test는 FPGA package 규칙만 확인했다. 실제 board 배선은 P1.5~P1.7에서 확인했다.

당시 manual로 확정하지 못한 PCIe PERST#는 P1.7에서 L16으로 확인했다. fan pin과 UART 방향은 아직 미확인이다.

## 6. 한계와 다음 단계

- 물리 LED·key 배선은 확인하지 않았다.
- DDR3 calibration과 PCIe DMA는 다음 단계에서 확인했다.
- 보드 성능과 resource는 Phase 3에서 측정했다.
